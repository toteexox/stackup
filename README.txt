GitHub sample 저장소의 index.html, app.js, style.css만 교체하세요.

변경 내용:
1) 전날/오늘 미션 전환 버튼을 날짜 표시줄에서 제거하고, 진도 트래커의 ‘오늘의 미션’ 제목 오른쪽으로 이동 (카드 목록 바로 위)
2) 좌측 하단 버전 라벨 숨김
3) 우측 하단 로그 버튼 평소 숨김. 필요 시 사이트 주소 뒤에 ?debug=1 을 붙여 진단 버튼 임시 노출 (예: https://toteexox.github.io/sample/?debug=1)
4) 아이폰 M4 롤백에서 녹음 성공한 코드(app.js)는 수정하지 않음. 전날 미션 날짜 로직도 변경하지 않음.

주의: 기존 버전의 playFallbackTTS 오류 및 첫 녹음 입력 문제에 대한 별도 수정은 포함하지 않았습니다. 이번 릴리스는 버튼 배치 및 진단 UI 숨김만을 위한 최소 변경판입니다.
