Stack Up 한국시간(KST) 통합 수정 - 사용자 최종 app(1).js 기반

적용: 현재 사이트의 app.js만 이 폴더의 app.js로 교체하세요.
캐시 때문에 반영이 안 되면 index.html에 있는 app.js?v=... 쿼리값만 새 값으로 변경하세요.

적용 기능:
- 상단 현재 시각: 전 세계 접속 위치에서 한국 시간(Asia/Seoul)으로 표시
- 미션 현재일/전날 버튼/오늘의 미션 판정: KST 날짜 및 요일로 통일
- 주말에 월요일 미션이 미리 열리는 문제 방지
- 미션 완료 시간: Firestore는 기존 ISO UTC 그대로 저장, 화면의 완료 체크는 한국 시간 표기
- 관리자 마지막 로그인 시간: KST 표기
- 관리자 패널티: 미션 예정일 다음날 오전 02:00 KST부터, 저장된 실제 완료시각(UTC)과 비교
- 과거 타임스탬프가 없는 완료 플래그(true)는 종전 완료 처리 유지(소급 패널티 방지)

중요:
- 사용자의 시스템 시계 자체가 부정확한 경우까지 서버에서 강제 보정하는 기능은 아님.
- 녹음/재생 엔진, 카드 상태·성취도, Firebase 저장형식, 줍줍/자동학습 동작은 수정하지 않음.
- app.js 이외의 파일, Firestore 데이터, HTML/CSS는 수정하지 않음.
- 모바일/PWA 기기 실동작은 별도 확인 필요.
