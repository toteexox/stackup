Stack Up - 최초 학습 카드 성취도 필수 (M6)

기준 파일: 사용자가 제공한 app(1).js에서 파생된 KST 통합 수정본
수정 범위: app.js 의 nextCard(e) 함수 단 1곳

규칙:
- 오늘 미션 / 지난 미션 / 학습 및 줍줍 버닝모드 등, 수동 학습에서
  처음 평가하는 카드(술술/버벅/막힘 기록 없음)에서 [다음 카드]를 누르면 평가 팝업 표시.
- 팝업에서 선택하면 카드별 기록 저장 -> 2일차 UE 줍줍 팝업(해당 시) -> 다음 카드.
- 기존에 평가한 카드는 팝업 없이 다음 카드로 이동.
- 이전 카드로 이동 시 강제하지 않음.
- 자동학습 루프는 듣기 복습이며 카드 성취도/진도 변경 없이 기존대로 진행.
- 녹음/재생, 마이크 audio:true, KST 날짜, Firebase 저장, CSS/HTML 변경 없음.

적용: app.js 교체. 브라우저/PWA 캐시 갱신을 위해 index.html의 app.js?v= 쿼리만 갱신.
최소 수정 원하면 변경부분만.patch 의 nextCard 차이만 현재 JS에 직접 적용.
주의: 실기기와 Firebase 연동 테스트는 별도 필요.
